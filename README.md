## Что пошло не так
Кратко:
1. Ошибка: Невозможно найти пакет pstree.
> pstree входит в пакет psmisc. Установил его командой `sudo apt install psmisc`.
2. mandb: fopen /var/cache/man/pt_BR/1257: Отказано в доступе . Восстановление прав и владельца директории /var/cache/man
> Восстановил правильные права и владельца директории `/var/cache/man`.
```
sudo chown -R root:root /var/cache/man
sudo chmod -R u+rwX,go+rX /var/cache/man
sudo mandb
```
3. -bash: kill: (1689) - Нет такого процесса. При попытке удалить зомби командой kill появилась ошибка, потому что зомби процесс уже не выполняется, его нельзя завершить обычным kill.
> После завершения родительского процесса зомби автоматически исчез.
