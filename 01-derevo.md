# Задание 1. Дерево процессов

1. `pstree -p | head -40` - показывает процессы системы в виде дерева, отображая взаимосвязи между родительскими и дочерними процессами. Ключ `-p` показывает PID процессов
```
systemd(1)-+-VGAuthService(674)
           |-agetty(720)
           |-cron(653)
           |-dbus-daemon(656)
           |-dhcpcd(698)-+-dhcpcd(699)-+-dhcpcd(994)
           |             |             |-dhcpcd(996)
           |             |             `-dhcpcd(1015)
           |             |-dhcpcd(700)
           |             `-dhcpcd(701)
           |-sshd(728)---sshd-session(1040)---sshd-session(1071)---bash(1072)-+-head(1378)
           |                                                                  `-pstree(1377)
           |-systemd(1047)---(sd-pam)(1049)
           |-systemd-journal(385)
           |-systemd-logind(673)
           |-systemd-timesyn(412)---{systemd-timesyn}(418)
           |-systemd-udevd(417)
           `-vmtoolsd(678)-+-{vmtoolsd}(789)
                           |-{vmtoolsd}(799)
                           `-{vmtoolsd}(800)
```
В корне дерева находится процесс systemd(1). От него запускаются системные процессы: cron, dbus-daemon, sshd, systemd-journal, vmtoolsd и другие. В выводе также видна оболочка bash(1072), которая запущена через цепочку sshd -> sshd-session -> sshd-session -> bash.

2. `echo $$` - выводит PID текущей оболочки Bash.
```
1072
```
PID текущей оболочки Bash равен 1072.


3. `ps -o pid,ppid,user,cmd -p $$` - (опиши команду)
```
    PID    PPID USER     CMD
   1072    1071 user     -bash
```
Процесс bash имеет PID 1072, его родительский процесс имеет PID 1071. Процесс принадлежит пользователю user.

4. ps -o pid,ppid,user,cmd -p 1071 - (опиши команду)
```
    PID    PPID USER     CMD
   1071    1040 user     sshd-session: user@pts/0
```
Процесс sshd-session имеет PID 1071, принадлежит пользователю user, а его родитель имеет PID 1040. Этот процесс отвечает за текущую SSH-сессию пользователя.

## Итоговый отчёт

1. **фрагмент вывода `pstree -p`, где видна ваша оболочка**
> -sshd(728)---sshd-session(1040)---sshd-session(1071)---bash(1072)-+-head(1378)
                                                                  `-pstree(1377)

Здесь видно, что текущая оболочка bash(1072) запущена внутри SSH-сессии.

2. **Вся цепочка от вашей оболочки до PID 1 в виде таблицы: PID, PPID, пользователь,
команда**

| PID | PPID | Пользователь | Команда |
|---|---|---|---|
| 1072 | 1071 | user | -bash |
| 1071 | 1040 | user | sshd-session: user@pts/0 |
| 1040 | 728 | user | sshd-session |
| 728 | 1 | root | sshd |
| 1 | 0 | root | systemd |

3. **Какой процесс стоит в корне дерева и почему у него нет родителя**

> В корне дерева находится systemd с PID 1. У него нет обычного родительского процесса, потому что systemd является первым процессом, который запускается ядром Linux во время загрузки системы. Поэтому его PPID равен 0.

4. **Сколько всего процессов работает в системе ( `ps aux | wc -l` ) и почему большинство
из них в состоянии S**

> 188 - Большинство процессов находятся в состоянии S (Sleeping), потому что они в данный момент не выполняют вычисления, а ожидают события: ввода-вывода, сетевых данных, таймера, сигнала или другого системного события.
